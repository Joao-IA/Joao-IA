# João Victor Fernandes de Castro

Estudo Inteligência Artificial na UFG e faço pesquisa no CEIA/UFG. Trabalho com dados desde 2023, quando entrei como estagiário de BI, e hoje divido o tempo entre análise de dados, machine learning e segurança de LLMs.

## Projetos atuais

- **Argos**: assistente de checagem de fatos feito pela UFG em parceria com a Anatel e o TSE de Goiás. Cuido do backend em Python (FastAPI) e da integração com o Gemini.
- **Detecção de deepfakes de áudio**: modelos que identificam fala sintética em português, e testes de quanto eles generalizam para idiomas que não viram no treino.
- **Segurança de LLMs**: avaliação de guardrails contra prompt injection e jailbreak. O repositório do grupo de estudos é o [LLM-Firewall](https://github.com/Joao-IA/LLM-Firewall).

## Publicações
